# 统一语言术语表（Ubiquitous Language）

> Lab 3 事件风暴产出，≥30 个术语
> 全员共用同一套语言，避免歧义

---

## 用户与身份

| 术语 | 定义 |
|---|---|
| 用户（User） | 注册并通过邮箱验证的平台使用者 |
| 提问者（Asker） | 发布问题的用户 |
| 回答者（Answerer） | 发布回答的用户 |
| 管理员（Admin） | 有权管理内容和标签的角色 |
| 昵称（Nickname） | 用户在平台上的显示名，全局唯一 |
| 邮箱验证（Email Verification） | 通过邮件链接确认邮箱归属 |

## 问题与回答

| 术语 | 定义 |
|---|---|
| 问题（Question） | 用户发布的求助帖，带标题和正文 |
| 回答（Answer） | 对问题的解答，属于某个问题 |
| 采纳（Accept） | 提问者标记某个回答为正确答案 |
| 已解决（Solved） | 问题状态，有回答被采纳 |
| 未回答（Unanswered） | 问题状态，还没有任何回答 |
| 标签（Tag） | 问题的分类标记，如 "Java"、"Spring Boot" |

## 投票与声誉

| 术语 | 定义 |
|---|---|
| 投票（Vote） | 对问题或回答的赞成/反对标记 |
| 赞成票（Upvote） | 表示内容有用的投票 |
| 反对票（Downvote） | 表示内容质量差的投票 |
| 声誉（Reputation） | 用户的积分，由投票和采纳累积 |
| 排行榜（Leaderboard） | 按声誉排序的用户 Top 列表 |
| 徽章（Badge） | 达成特定里程碑的成就标记 |
| 悬赏（Bounty） | 提问者用自己的声誉吸引回答 |

## 搜索与通知

| 术语 | 定义 |
|---|---|
| 搜索（Search） | 按关键词查找问题和回答 |
| 搜索索引（Search Index） | 为快速搜索建立的倒排索引 |
| 通知（Notification） | 系统推送给用户的消息 |
| @提及（Mention） | 在内容中用 @昵称 提醒某人 |
| 相关问题（Related Questions） | 按标签和相似度推荐的其他问题 |

## 架构与技术

| 术语 | 定义 |
|---|---|
| 聚合（Aggregate） | 领域中一组关联对象的边界，是数据修改的最小单元 |
| 领域事件（Domain Event） | 领域中发生的、值得关注的事实 |
| 限界上下文（Bounded Context） | 领域驱动设计中的功能边界 |
| Outbox 模式 | 用事务表保证领域事件最终发布的模式 |
| 防腐层（Anti-Corruption Layer） | 隔离外部系统的适配层 |

## 流程与协作

| 术语 | 定义 |
|---|---|
| 用户故事（User Story） | 用"作为...我希望...以便..."格式写的需求 |
| 验收标准（Acceptance Criteria） | 一个 Story 完成的判定条件 |
| Gherkin | Given-When-Then 格式的验收语言 |
| Sprint | 2-4 周的迭代周期 |
| Backlog | 待完成的需求列表 |
| DoD | Definition of Done，完成定义 |
