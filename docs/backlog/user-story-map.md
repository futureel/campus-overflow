## 按 Sprint 切片

| Sprint | 包含的活动 | 交付 |
|---|---|---|
| **Sprint 2** | 注册登录 + 发布问题 + 回答/投票/采纳 | 能提问、能回答、能投票的基本闭环 |
| **Sprint 3** | + 搜索 + 声誉积分 + 排行榜 + @通知 + 悬赏 | 有社区氛围的完整产品 |
| **Sprint 4** | + 评论 + 徽章 + 收藏 + 移动端 + Markdown 预览 | 打磨体验后上线 |

## 工作坊现场操作步骤

1. **每人 10 分钟**：在便签上写 5-8 个用户故事（格式：作为...我希望...以便...）
2. **每人轮流贴**：把便签贴到对应的活动列下面
3. **PO 归类**：张宇航把重复的合并，把放错列的挪位置
4. **画 MVP 线**：大家一起决定第一版要做哪些，用横线划出来
5. **排优先级**：同一列里，最想先做的贴最上面
6. **拍照存档**：工作坊结束后拍照，和这份框架一起存档
